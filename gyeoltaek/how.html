자동화 디지털 상품

주문하면 텍스트가 만들어지고, 메일로 가

실물을 만들지 않고, 보내지도 않아. 결제 기능은 아직 연결하지 않았어.

흐름

  1. 주문. 나중에 스마트스토어나 이 사이트에서 상품을 결제한 뒤.
  2. 정보 입력. 받을 이메일, 생년월일, 출생 시각, 출생지(선택). 결혼 궁합은 두 사람 분.
  3. 생성. 서버가 오락용 안내 문구를 포함한 텍스트를 만들어.
  4. 전달. 입력한 메일로 본문 또는 기한 있는 다운로드 링크를 보내. 판매자가 택배 송장을 넣지 않아도 되게, ‘배송 없음’으로 처리하는 게 목표야.

스마트스토어 참고. 스토어 자체에는 파일 자동 발송 기능이 없어. 전자책 판매자들은 ‘배송 없음’으로 두고, 직접 입력형 옵션으로 이메일을 받은 뒤 발송 처리를 하거나, 센드맨 같은 외부 도구를 연동해. 다만 센드맨은 미리 올려 둔 파일을 보내는 쪽에 가깝고, 주문마다 다른 출생 정보로 새 리포트를 만들려면 스마트스토어 커머스 API로 주문을 읽어 우리 쪽이 생성·발송하는 쪽이 맞아.

2025년 11월부터 비실물 상품 제한이 강화됐어. 공식 취급불가 목록에는 무속의식(무당굿 등)이 있고, 여러 매체는 ‘운세·연애 등 1회성 유·무선 상담’은 예외로 허용된다고 전했어. 자동 생성 PDF가 그 예외에 해당하는지는 판매자센터 공지 원문으로 지성이 한 번 더 확인해야 해. 명리학 강의처럼 여러 회차 온라인 강의는 제한 대상이야.
